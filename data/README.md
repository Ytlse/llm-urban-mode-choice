# data/

Simulation data. The sealed substrate and the experiment definitions are versioned;
the caches, the large feeds and the executions can be regenerated and stay out of the repository.

## Structure

```
data/
├── population/                        # Reference substrate
│   ├── population_1000_PANEL_v5/      # SEALED cohort (1,000 personas) — the only one in service
│   │   ├── population.json            #   the file the loader reads
│   │   ├── MANIFEST.yaml              #   sealing fingerprint (population.sha256)
│   │   ├── CONTROLE.md                #   the thirteen control margins
│   │   ├── report.json / selection.json
│   ├── toulouse_population_1000_PANEL.json   # declared source, same fingerprint (provenance)
│   ├── sauvegardes/                   # .tar.gz of cohorts v1 → v5
│   └── archive.zip                    # cohorts v1/v3/v4 and pre-seal populations
│
├── jeux/                              # Proposal sets (MANIFEST + propositions.jsonl)
│   ├── population_1000_PANEL_v5_<date>/
│   └── archive.zip                    # set sealed against v1
│
├── experiences/                       # Experiment definitions (experience.yaml, versioned)
│   ├── archive_v1_2026-09-11/         # definitions of the v1 campaign — without the executions
│   └── archive_v1_2026-09-11.zip      # the complete campaign, executions included
│
├── cache/                             # Regenerable caches (out of the repository)
│   ├── eqasim/                        # cache of the population synthesis pipeline
│   ├── llm/                           # semantic cache of LLM responses
│   ├── osmnx/                         # serialised road graphs + study area
│   │   ├── graphs_444ca7e6a515.pkl    #   graph IN SERVICE (+ .meta.json and boundary_…)
│   │   └── perimetre_453/             #   OSM extracts of the polygon of the 453 communes
│   └── otp/                           # stored itineraries (otp_cache.db)
│
├── gtfs/                              # OTP input — mounted read-only on /var/otp/toulouse
│   ├── Toulouse.osm.pbf               # base map
│   ├── graph.obj                      # multimodal graph IN SERVICE (authoritative)
│   ├── tisseo_gtfs/                   # urban network
│   ├── lio_gtfs/                      # regional coaches
│   ├── ter_gtfs/                      # regional trains
│   ├── build-config.json              # copied from services/otp-toulouse/toulouse/ by `make otp-graph`
```

## Mounts in the containers

| Host | Container |
|---|---|
| `data/population` | `/data/eqasim-output` (controller), `/eqasim-output` (eqasim) |
| `data/gtfs` | `/var/otp/toulouse` (otp1/2/3, read-only), `/data/gtfs` |
| `data/cache/osmnx` | `/app/osmnx_cache` and `/app/data/cache/osmnx` |
| `data/cache/otp` | `/app/data/cache/otp` |
| `data/cache/llm` | `/app/data/llm_cache` |
| `data/cache/eqasim` | `/eqasim-cache` |
| `data/jeux`, `data/experiences` | `/app/data/…` |
| `data/weather` | `/app/data/weather` and `/data/weather` |
| `data/prometheus_data` | `/prometheus` |

## Which graph is authoritative

`data/gtfs/graph.obj` — the one loaded by the three OTP instances, which mount `data/gtfs`
entirely. The setting `settings.gtfs.gtfs_file` points to `data/gtfs/tisseo_gtfs/`, but
`sim_clock.py` only reads `agency.txt` and the calendars there: never a graph.

Rebuild: `make otp-graph` (~55 s). The old graph is moved to
`archives/<date>_pre_build/`, never overwritten.

## DVC

`gtfs.dvc`, `eqasim_output.dvc`, `po_toulouse.small.dvc`, `population_samples.dvc`.
`dvc pull` fetches the corresponding folders — `po_toulouse.small/` and `population_samples/`
are no longer on disk: they have no reader in the code.

## Caches

| Folder | Regenerated by |
|---|---|
| `cache/eqasim/` | eqasim pipeline (2.4 GB — do not empty without reason, the resynthesis is long) |
| `cache/llm/` | first LLM call of each experiment |
| `cache/osmnx/` | start of the OSMnx service; `perimetre_453/` by `build_osmnx_perimeter_graph.py` |
| `cache/otp/` | first itineraries computed |

Emptying a cache while a container is running leaves the service writing into an unlinked file:
stop the stack (or at least `controller` and `osmnx1`) before, or restart them after.
